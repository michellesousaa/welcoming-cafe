A personal portfolio showcasing UX/UI case studies and front-end development projects.

## Case Studies

### AR AstroQuest
An immersive, AR-based educational experience designed to help children explore the solar system in an interactive and engaging way. The project focused on designing for a young audience — balancing visual excitement with clear, intuitive navigation. Research, user flows, and high-fidelity prototypes were built in Figma, with accessibility and engagement as the core design goals.

### ABC Academy Mobile App
A full UX case study for a mobile app serving ABC Academy clients. The process covered discovery interviews, competitive analysis, persona development, and iterative prototyping. The goal was to reduce friction in the client experience and create a seamless path from enrollment to ongoing engagement — all grounded in real user research.

### Align Internship: UX/UI Case Study
Completed during a UX design internship at Life Stages (Align App), a wellness platform built for women. Contributed to designing stress-relief and mindfulness features, conducted user interviews and surveys, and translated findings into wireframes and high-fidelity prototypes in Figma. Focused on creating a calm, accessible, and personalized onboarding and daily-use experience.

## Development Projects

### PuzzleMate
[Live Site](https://puzzlemate.netlify.app/)

An interactive chess training web app where users select a difficulty level and solve curated tactical puzzles on a fully interactive board. The app provides real-time feedback and guides users toward the correct solution, making it useful for casual players and competitive enthusiasts alike.

**Tech Stack**
- React
- JavaScript
- HTML / CSS
- Netlify

**Retrospective**  
PuzzleMate was my first fully deployed React project, and it taught me a lot about state management and working with interactive UI components. If I were to revisit it, I would expand the puzzle library significantly to give users more variety and replayability. I would also invest more time in the landing page — it currently gets users to the app quickly, but it could do more to communicate the value of the tool and hook new visitors with better visual storytelling and onboarding.

---

### Welcoming Cafe
[Live Site](https://welcomingcafe.netlify.app/)

A fully responsive cafe website designed to give a small business a warm, professional online presence. The site includes a homepage, menu browsing, location and hours, and a contact section. The focus was on mobile-first layout, clean typography, and a visual identity that reflects the cafe's inviting atmosphere.

**Tech Stack**
- HTML
- CSS
- JavaScript
- Netlify

**Retrospective**  
This project was a good exercise in building a polished, real-world site from scratch without a framework. Looking back, I would spend more time on the visual design layer — specifically tightening the spacing system, establishing a stronger typographic hierarchy, and ensuring visual consistency across every section of the interface. The functionality is solid, but a more refined design pass would bring the overall experience closer to the standard I hold for my UX work.
